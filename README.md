# AI ORDA — FAQ-бот

Hackathon team repository for AI ORDA. Трек 03 — «LLM-приложения».
Терминалдағы бот репетиция туралы 5 тақырыпқа жауап береді: уақыт, команда,
трек, тапсыру, сыйлықтар. Python 3.9+ қажет; сыртқы кітапхана, интернет және
API кілті қажет емес.

Репозиторийді жүктеп, оның бумасында іске қосыңыз:

```sh
python3 main.py
```

```text
> Сыйлық бар ма?
Бұл репетицияда сыйлықтар жоқ.
> Какой у нас трек?
Таңдалған трек — 03: LLM-приложения. ...
> Ауа райы қандай?
не знаю
> шығу
```

Логика әріп регистрін, тыныс белгілерін және `ё/е` айырмасын қалыпқа келтіреді.
Алдымен FAQ сұрағымен дәл сәйкестікті, кейін қазақша/орысша толық кілт сөздер
мен тіркестерді іздейді. Ұзағырақ тіркес басым; қайталанған сөз ұпай қоспайды.
Ең жоғары ұпай тең болса немесе сәйкестік болмаса — `не знаю`.
Бұл сөздікке негізделген тәсіл: еркін парафраздар, емле қателері және барлық
сөз мағыналары танылмайды. Жауаптар тек `faq.txt` файлынан алынады.

`faq.txt` — UTF-8 JSON форматындағы дәл 5 жазба; әрқайсысында `topic`,
`question`, `answer`, `keywords` бар. Нақты кесте мен команда саны белгісіз
екені жауаптарда көрсетілген. Ұйымдастырушы бергенде сол файлды жаңартыңыз.
Шығу: `exit`, `quit`, `шығу`, `выход`, Ctrl+C немесе EOF.

Локал тексеру:

```sh
python3 -m unittest -v
```
